# 00 · End cards

Ready-made closers for the real footage. Cut from your last shot and drop one in. Each opens with the signature zip, which is the brand's sound logo: "start or end every video with the logo and the signature zip sound". 3.2 s, 1080×1920, 60 fps.

| File | Use it for |
|---|---|
| `stimpy_endcards_logo-black.mp4` | Teasers and macro shots (Edge Zip, Sound First) |
| `stimpy_endcards_logo-coral.mp4` | Key posts (Empty Frame) |
| `stimpy_endcards_logo-white.mp4` | Light, daytime footage |
| `stimpy_endcards_soon.mp4` | "The back changes. Soon." (all the Hidden Back ideas) |
| `stimpy_endcards_something.mp4` | "Something goes here. Soon." |
| `stimpy_endcards_date.mp4` | The launch date (**placeholder `14.11`**: set `LAUNCH` in `app/src/films/06_the_reveal/index.ts`) |

Re-render: `cd app && node scripts/render.ts all --film endcards`
