# 03 · D · The Perfect Loop

**Shoot brief for the real-footage version of the idea. 9:16, 8 s, seamless loop.**

Shot from overhead: the pull goes all the way round the Stimpie, the panel lifts a little and settles, and the pull goes all the way back, landing on exactly the first frame. The Reel loops forever, and loops raise watch time.

## Files
- `stimpy_perfectloop_clean.mp4`: the animatic. It shows the timing, framing and sound to aim for.
- `stimpy_perfectloop_notes.mp4`: the same film with the shoot notes on screen (shot number, what to do). Give this one to whoever is filming.
- `perfectloop_clean_sheet.png`: contact sheet. `.wav`: the animatic soundtrack.

## Kit
- A tripod straight above
- A small piece of tape
- A cream surface and window light

## Setup
Put the phone directly above. Mark the pull's starting position with tape (just out of frame, or under the hand). Don't move the hoodie between takes.

## Shot list (timed to the animatic)
| Time | Shot | How |
|---|---|---|
| 0.0 s | **Overhead, Stimpie on** | The hand is already pinching the pull, which rests on the mark. |
| 0.5 s | **Unzip all the way round** | One steady pull round the whole edge. Keep the hand at the same angle the whole way. |
| 3.25 s | **The breath** | Lift the panel a few cm by the pull, then set it back down. |
| 4.5 s | **Zip it back** | At the same speed, all the way back to the tape mark. |
| 7.25 s | **Land on frame one** | Stop exactly on the mark. Trim so the last frame equals the first. No end card: it has to loop. |

## Sound
The real zip, both ways. If you add music, use a track whose length matches the loop exactly (8 s = 16 beats at 120 bpm).

## Edit
Check the loop by playing it on repeat in CapCut. Any jump at the cut gives it away.

## Caption
"How many times did you watch this?"
