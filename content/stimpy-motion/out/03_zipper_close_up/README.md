# 03 · Zipper Close-Up: shoot ideas

**Brief:** Slow, tight shots of the one-way zipper closing, with a satisfying sound and no explanation. It should spark guesses in the comments.

Each idea below is a filmable concept for the real footage. Each folder has:
- an animatic, to watch the timing, framing and sound;
- the same animatic with the shoot notes on screen, for whoever films;
- a shoot brief (`README.md`) with the kit, setup and a timed shot list.

| Idea | Length | In one line |
|---|---|---|
| [The Edge Zip](a_the_edge_zip/) | 10 s | Macro along the Stimpie edge: the pull turns a corner, and the last tooth clicks. |
| [Sound First](b_sound_first/) | 9 s | A black screen with only the zip sound, then a hard cut to the macro on the clack. |
| [The Empty Frame](c_the_empty_frame/) | 10 s | Overhead: a hand zips an empty frame closed round nothing. "Something goes here." |
| [The Perfect Loop](d_the_perfect_loop/) | 8 s, seamless loop | Overhead: unzip all the way round and back, landing on frame one so it loops forever. |

Every one ends on a ready-made card from [`../00_end_cards`](../00_end_cards/), which carries the signature zip sound.

> The old renders still in this folder (stimpy_zipper.mp4/.wav, zipper_sheet.png) are the first motion version you didn't like. It has been replaced by the ideas above. Delete it whenever you like.
