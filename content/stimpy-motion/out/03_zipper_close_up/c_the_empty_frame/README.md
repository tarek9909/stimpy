# 03 · C · The Empty Frame

**Shoot brief for the real-footage version of the idea. 9:16, 10 s.**

Shot from overhead: a black hoodie lies flat on a cream table, back up, with **no Stimpie on it**. A hand zips the empty track all the way round a rectangle. The frame closes around nothing. "Something goes here."

## Files
- `stimpy_emptyframe_clean.mp4`: the animatic. It shows the timing, framing and sound to aim for.
- `stimpy_emptyframe_notes.mp4`: the same film with the shoot notes on screen (shot number, what to do). Give this one to whoever is filming.
- `emptyframe_clean_sheet.png`: contact sheet. `.wav`: the animatic soundtrack.

## Kit
- A tripod or a shelf to hold the phone straight down
- A cream or beige surface (a table, paper, a sheet)
- Window daylight

## Setup
Put the phone directly above, looking straight down. Lay the hoodie flat and smooth it out. Let window light come from one side. The open zip track should be clearly visible.

## Shot list (timed to the animatic)
| Time | Shot | How |
|---|---|---|
| 0.0 s | **Overhead, hoodie flat** | The hoodie is still. Hold 1 s. |
| 1.0 s | **Start the zip, slowly** | A hand enters from the bottom right, pinches the coral pull and starts round the empty frame. |
| 2.0 s | **Speed ramp** | One continuous take. In the edit, speed the middle up 4–6×. |
| 4.0 s | **The last corner** | Back to real speed for the last stretch, so we hear the last teeth. |
| 5.2 s | **Snap. Let go.** | The hand leaves the frame. Hold on the closed, empty frame for 2 s. |
| 6.0 s | **Text** | "Something goes here." (add in the edit, top of frame). |
| 8.2 s | **End card** | Add `00_end_cards/stimpy_endcards_logo-coral.mp4`. |

## Sound
The real zip sound. When sped up, the clicks become a fast whirr, which is satisfying. Add a light, curious music bed.

## Edit
CapCut → Speed → Curve. Shape the speed so it is slow, then fast, then slow.

## Caption
"Something goes here."
