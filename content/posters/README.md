# Stimpy posters

These are 1080 x 1350 PNGs. To export them again:

```sh
cd content/videos/stimpy-motion/app
node scripts/posters.ts
```

The designs are in `content/videos/stimpy-motion/app/src/posters/posters.ts`. A re-export doesn't update the copies in `calendar/posts/`, so copy any changed poster there too.
