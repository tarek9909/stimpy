# Stimpy calendar

## Documents

| File | Use it for |
|---|---|
| [STIMPY_CALENDAR.md](STIMPY_CALENDAR.md) | The working plan: dates, captions, ads and the Stories checklist. It wins if documents disagree |
| [META_SCHEDULING.md](META_SCHEDULING.md) | Scheduling the feed posts in Meta, with progress in its Results table |
| [VIDEOS_TO_BUILD.md](VIDEOS_TO_BUILD.md) | The videos still to shoot or edit |
| [HANDOFF.md](HANDOFF.md) | Background: what was decided, why, and what's still open |

## Folders

| Folder | What's in it |
|---|---|
| `posts/` | Every file to post, in date order. Names follow `YYYY-MM-DD_HHMM_type_name`. `ADD-*.txt` notes mark files still missing |
| `_covers/` | Reel covers and contact sheets |
| `_previews/` | The preview images shown in the calendar |
| `_archive/replaced-originals/` | Earlier versions of replaced videos. Don't post these |
| `_archive/fixed-exports/` | Exports as received, with their source diffs. The current copies are in `posts/` |
