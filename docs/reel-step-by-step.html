Stimpy reel: shoot and edit, step by step

Galaxy S24 Ultra → Adobe Premiere Pro · 1080×1920, 30 fps, ~14 s · music ~101 BPM (confirm it) · hard cuts only

PART 1. Before you shoot

What to bring / have ready

  • Both hoodies: Black and Cream, ironed flat (wrinkles read badly from above)
  • All 11 Stimpies, stacked in this order: Sabotage (hook/payoff), then for the black hoodie Bubblegum, Tiger, Unhinged, Ducks, Receipt, then for the cream hoodie Neon, Public Persona, Chameleon, Same Day, Drama
  • Phone on tripod / overhead arm, lens pointing straight down; a remote, or use the 2 s timer
  • Studio light at the side with a diffuser; lint roller
  • Tape (4 corner marks per hoodie), warm mid-tone surface, props: cassette, receipt, VHS tape, duck
  • Plain top without logos, hair tied back, no rings or watches (they glint)
  • Phone: full battery, 20 GB free (4K 30 is about 400 MB per minute), Do Not Disturb on

Camera settings (check once, then do not change)

SettingValue
Mode / lensVideo → More → Pro Video, 1x, phone in portrait
ResolutionUHD 30 (not 24). Use 60 only if you want slow-mo.
HDR10+ / LOGBoth off
ISO / shutterISO 50–100, 1/50 s (use 1/60 if your power is 60 Hz)

Per hoodie: the black hoodie needs a little more light, and the cream one clips easily. Re-set ISO only when you switch hoodies, check the histogram, and keep the white balance the same.

Slate every clip

  • Start recording, wait 1 s with nothing moving, do the action, wait 1 s after, stop. These extra seconds are your handles for trimming.
  • Name each clip in the gallery or right after import using the names in the table below.

PART 3. Premiere, step by step

Step 1. Import and set up

  1. Copy clips to your computer (cable or Quick Share). Check each one plays smoothly. If a clip stutters, right-click → Proxy → Create Proxies (H.264 low-res), or transcode it.
  2. File → New → Sequence → Settings tab → Editing mode Custom, Timebase 30 fps, Frame size 1080 horizontal × 1920 vertical, Pixel aspect Square. Name it stimpy_reel.
  3. Make bins: 01_clips, 02_music, 03_sfx. Rename clips as in Part 2.
  4. Drag the first clip to the sequence. If Premiere asks, choose Keep existing settings. Then set each 4K clip to Scale 50 in Effect Controls (3840×2160 portrait fills 1080×1920 at 50%). Or right-click → Set to Frame Size.

Step 2. Music and beat markers

  1. Put the song on A1. Trim the start so the first strong beat lands at 00:00:00:00. If the track starts later, add that offset to every marker time below.
  2. Confirm the tempo: play and press M in time with 8 beats, then check that the spacing is about 0.594 s (18 frames). If it's not, work out new spacing (beat = 60 ÷ BPM s) and ignore the table.
  3. Click the timecode field, type each time from the table below, press Enter, then press M. Do this 25 times. Turn Snapping on (S).

Step 4. Polish

  1. Match the two hoodies: in Lumetri Color → Basic Correction, adjust Exposure so black-hoodie and cream-hoodie clips feel equally bright. Contrast +10, Saturation 105–110, Temperature slightly warm.
  2. Align: for any clip where the hoodie sits a few pixels off, adjust Position in Effect Controls. Never use transitions.
  3. Audio: music peaks around -6 dB. The zipper sound from the clips goes on A2 at about -18 dB, under the music. Add a zip sound on the end card.
  4. Text: if you add any, keep it out of the top 14% (about 270 px) and bottom 25% (about 480 px).
  5. Play the whole thing once with the sound on, looking for position jumps and clipped highlights.

Step 5. Export

  1. File → Export → Media. Format H.264, preset Match Source – High bitrate.
  2. Video: 1080×1920, 30 fps, VBR 1-pass, target 10–12 Mbps, max 16. Audio: AAC 320 kbps, 48 kHz.
  3. Export a version without music if you plan to add the song from Instagram’s library, to avoid copyright muting.
  4. Watch the file on your phone before posting.
If something goes wrong: clips stutter → make proxies. Hoodie jumps between clips → adjust Position, and next time re-tape the marks. Flicker bands in the footage → shutter should match your power frequency (1/50 or 1/60). Dark panels vanish on the black hoodie → keep them on the cream one.
